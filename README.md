# Finance Manager

A simple personal finance manager written in C++.

## Current features

- Add income
- Add expenses
- Display balance
- Display total income and expenses
- Display transaction history
- Basic input validation
- Menu input validation

## Technologies

- C++
- STL (`vector`, `string`)
- Git / GitHub
